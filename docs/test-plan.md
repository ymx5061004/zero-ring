# 《零环》0.2 手动测试清单

本项目不引入自动化测试框架；以下为发布前的人工回归清单。建议在桌面浏览器（开发服务器 `npm run dev`）与一台真机（同局域网访问）各跑一遍。

> 提示：开发模式下，浏览器控制台暴露了 `window.zeroRing`（Phaser.Game 实例）。可用 `zeroRing.scene.start('GameScene', { classId: 'ring-knight' })` 直接进入指定职业，便于定向测试。

## 0. 冒烟（每次必跑）
- [ ] `npm run build` 通过（含 `tsc` 类型检查）。
- [ ] 启动后无控制台报错；标题 → 主菜单 → 选职业 → 进入游戏链路正常。
- [ ] 可移动、可近战、可捡物、可下楼、可死亡、可在第 5 层击败 Boss 胜利。
- [ ] 竖屏下底部 7 个动作键（技能 / 搜索 / 等待 / 背包 / 角色 / 日志 / 下楼）整齐排布、互不重叠、均可点击；横屏显示「请竖向放置」。

## 1. 动作经济
- [ ] 新游戏后背包 / 装备与所选职业的 `startingItems` 一致，且武器 / 防具 / 饰品已自动穿戴。
- [ ] 打开「背包 / 角色 / 日志」界面**不**消耗回合（怪物不动）。
- [ ] 在敌人相邻时：饮药 / 用卷轴 / 装备 / 卸装 / 搜索 / 开门 各**消耗一回合**，怪物随即行动一轮。
- [ ] 一次动作只触发一轮怪物行动（观察日志不出现重复结算）。
- [ ] 背包满时拾取失败有提示；可堆叠的消耗品仍可叠加拾取。

## 2. 职业技能（建议每个职业各测一次）
- [ ] **环骑士·环誓**：被动；致命一击时存活并回血，随后三回合「易伤」；每层仅一次（下楼恢复）。
- [ ] **灰烬医师·急救**：消耗法力，回血并净化中毒 / 灼烧等不良状态。
- [ ] **裂隙盗·穿墙**：弹出方向键，朝墙的方向穿过一格；每层有限次数；无法穿出时不消耗次数。
- [ ] **星盐法师·盐爆**：消耗法力，对周身范围怪物造成伤害并使其迟缓。
- [ ] **骨钟祭司·钟鸣**：消耗法力，使亡灵（undead）恐惧、其余怪物迟缓。
- [ ] **碎刃游侠·投掷**：方向键瞄准，命中直线第一名怪物造成重创 + 流血；空射不消耗次数。
- [ ] **铁拳僧·连击**：被动；连续命中同一目标伤害递增，换目标归零。
- [ ] **铜灯旅人·灯火**：照亮四周并照见较大范围隐藏陷阱，吓退潜影。
- [ ] **断链狂徒·狂怒**：被动；生命越低近战附加伤害越高。
- [ ] 法力不足 / 次数用尽 / 被动技能点「技能」键时，有相应日志提示且不消耗回合。

## 3. 远程攻击与法力
- [ ] HUD 右侧显示法力 `法 m/M`（仅法系职业）；步行若干回合后法力缓慢回升。
- [ ] 装备弓 / 法杖 / 魔杖后，点按**视线内、射程内**的怪物可远程攻击（有飞行弹道）。
- [ ] 隔着墙或**关闭的门**无法远程命中（点按无效，需先开门 / 换位）。
- [ ] 远程怪物（苔藓弓手 / 低语法球）有视线才射击，并会与你保持距离。

## 4. 物品实例、鉴定、祝福 / 诅咒、附魔
- [ ] 地面 / 掉落的药剂、卷轴显示为随机别名（如「浑浊的药剂」）；同一局别名固定。
- [ ] 使用某药剂 / 卷轴后，背包内同类立即显示真名。
- [ ] 「鉴物卷轴」一次性看清随身所有未鉴物品；「解缚卷轴」解除装备诅咒。
- [ ] 装备显示 +N/−N 附魔，且实际影响攻 / 防（角色面板数值对应变化）。
- [ ] 装上被诅咒的装备后无法普通卸下（有提示），用「解缚卷轴」后可卸下。
- [ ] 祝福 / 诅咒影响药剂回血量、卷轴效果强弱（祝福增强、诅咒减弱并令自身易伤）。

## 4b. 装备人偶（11 槽）
- [ ] 背包为三列人偶布局，11 槽（主手 / 副手 / 头部 / 肩甲 / 身体 / 腰带 / 手套 / 足部 / 护符 / 戒指 ×2）排布整齐、与背包格 / 详情 / 按钮互不重叠；空槽显示槽名、满槽显示图标。
- [ ] 装备进入正确槽位：盾→副手、盔→头部、靴→足部、肩甲 / 腰带 / 手套各归其位；两枚戒指分别进戒指一 / 戒指二。
- [ ] 点击已着装的槽位即卸下（被诅咒者除外）；卸下 / 装备影响角色面板对应属性。

## 5. 状态效果与抗性
- [ ] 中毒 / 灼烧每回合扣血并在 HUD 状态条显示（如「毒3」）；回复每回合加血。
- [ ] 迟缓的怪物半速行动；冰封的怪物跳过回合；恐惧 / 混乱的怪物逃离 / 乱走。
- [ ] 「易伤」目标受到的伤害明显提高。
- [ ] 抗性生效：灰烬医师抗毒、骨钟祭司抗精神等（中毒 / 恐惧更难生效或更短）。

## 6. 怪物特性与差异化 AI
- [ ] 低血逃跑（铜牙鼠 / 裂骨犬）会转身逃离。
- [ ] 偷金（铜牙鼠）命中后扣除金币并有提示。
- [ ] 毒袭（苔藓弓手）命中后使你中毒。
- [ ] 穿墙（盐井幽影）可穿过墙体移动；开门（无面巡逻者）会推开关闭的门。
- [ ] 死亡爆裂（灯蛾尸）炸伤相邻；死亡分裂（裂骨犬）裂成两只更小的骨兽（分裂体不再分裂）。
- [ ] 迟缓重击（镜壳虫 / 铁面傀儡）半速但伤害更高。
- [ ] Boss「零环守卫」生命低于 50% 触发一次第二阶段（属性提升 + 回复，有提示）。

## 7. 门、宝箱、陷阱、搜索
- [ ] 新层的门默认关闭 / 上锁（无预先敞开）；不出现沿墙成排的门。
- [ ] 关闭的门阻挡移动与视线；走向它即推开（消耗回合），开门后显示为「敞开门」贴图（与关闭门可区分）。
- [ ] 上锁的门需「踹门」，成功概率与攻击相关；失败可再试。
- [ ] 长按相邻的敞开门可将其关闭。
- [ ] 宝箱可能上锁（自动撬锁，概率与敏捷相关）或暗藏机关（开启时触发陷阱）。
- [ ] 隐藏陷阱：直接踩中会触发（尖刺扣血 / 毒气中毒 / 传送 / 索套迟缓）。
- [ ] 「搜索」可发现四周隐藏陷阱；走向已显露的陷阱会尝试拆除（失败则触发）。
- [ ] 怪物踩中陷阱同样会触发。

## 8. 存档与兼容
- [ ] 中途退出再「继续游戏」，职业 / 楼层 / 生命 / 法力 / 背包（含附魔、祝咒、鉴定状态）/ 金币 / 步数均正确恢复。
- [ ] 旧版存档可正常读取并继续：0.1（字符串物品→实例、补默认法力）、早期 0.2（旧三槽装备按真实槽位归位）。
- [ ] 死亡 / 胜利后存档被清除，历史统计（最深层数等）保留。

## 已知限制
- 状态中的「冰封 / 迟缓 / 混乱 / 恐惧」对**玩家**无强制行动效果（玩家由输入驱动）；对玩家有意义的主要是中毒 / 灼烧 / 回复 / 易伤。
- 远程攻击与定向技能采用「方向选择」模式而非任意格选靶，以适配移动端。

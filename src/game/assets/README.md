# assets

No third-party or copyrighted assets are used anywhere in 《零环》.

This folder holds **`atlas.ts`** — the loader/animation wiring for the game's
sprites. The sprites themselves are **generated by code**, not bundled:

- Generator: [`scripts/generate-assets.ts`](../../../scripts/generate-assets.ts)
  (a dependency-free Node script with its own PNG encoder).
- Output: `public/assets/generated/*.png` + `atlas.json` (the frame manifest).
- Regenerate: `npm run gen:assets` (also runs on `prebuild`, and on `npm run
  dev` if the sheets are missing).

UI chrome (buttons, menus, the ring emblem, the dungeon grid) is still drawn at
runtime with `Phaser.Graphics`. If you add your own **original** assets later,
load them in `BootScene.preload()`.

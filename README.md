# 零环（Zero Ring）

《零环》是一款**移动端竖屏、网页版**的单人地牢探索 **roguelike**，以传统回合制地牢爬行（NetHack/Pathos 一类）为**灵感**，但**所有内容均为原创**。它是一个可安装的 **PWA**：所有图形（角色、怪物、地块、物品、特效、应用图标）都由代码实时生成，不含任何第三方版权素材。

> 目标：逐层深入环窟（共五层），在最深处击败「零环守卫」，取回零环。1

**在线试玩**：<https://ymx5061004.github.io/zero-ring/>（推送到 `main` 后，由 GitHub Actions 自动构建并部署到 GitHub Pages）

## 技术栈

- [Vite](https://vitejs.dev/) —— 开发服务器与打包
- TypeScript（严格模式）
- [Phaser 3](https://phaser.io/) —— 游戏框架
- `localStorage` —— 本地存档与设置
- PWA：`manifest.json` + Service Worker（离线可用、可添加到主屏幕）
- 固定 **390 × 844** 竖屏设计，FIT 缩放适配任意屏幕与刘海/安全区域

## 安装

```bash
npm install
```

## 运行（开发）

```bash
npm run dev
```

打开终端中打印的地址即可游玩。开发服务器已开启 `host`，手机可经局域网访问同一地址在真机上测试。

## 构建（生产）

```bash
npm run build      # 类型检查 + 打包到 dist/
npm run preview    # 本地预览生产构建
```

`dist/` 为纯静态文件，可直接部署到任意静态托管。

## 生成像素素材

所有像素图与应用图标由脚本生成，无需下载：

```bash
npm run gen:assets
```

输出到 `public/assets/generated/`（spritesheet + `atlas.json`）与 `public/icons/`（PWA 图标）。该脚本也会在 `npm run build` 前（`prebuild`）以及缺少素材时的 `npm run dev` 自动运行。

## 玩法说明

- **五层环窟**：每次下楼生成全新地图，越深的楼层怪物越强。
- **回合制**：你每完成一次有效动作（移动、攻击、用物、施法、搜索、开门……），怪物随即行动一轮。打开界面不消耗回合。
- **战斗**：走向怪物即发起近战；命中、闪避、暴击、防御减伤俱全，并有浮动伤害与受击反馈。
- **职业技能（0.2）**：九大职业各有专属能力——环骑士的免死「环誓」、灰烬医师的急救、裂隙盗的穿墙、星盐法师的盐爆、骨钟祭司的钟鸣、碎刃游侠的投掷、铁拳僧的连击、铜灯旅人的灯火、断链狂徒的狂怒。被动技能自动生效，主动技能由底部「技能」键释放（需要方向时会弹出方向键）。
- **法力与远程（0.2）**：法系职业拥有法力，用于施放主动技能。装备远程武器（弓 / 法杖 / 魔杖）后，**点按视线内、射程内的怪物即可远程攻击**（不能穿墙或穿过关闭的门）。
- **状态效果（0.2）**：中毒、灼烧、冰封、混乱、恐惧、迟缓、易伤、回复——玩家与怪物皆可携带，每回合结算；并有毒 / 火 / 冰 / 精神抗性。
- **物品实例与鉴定（0.2）**：药剂与卷轴每局以随机别名出现，**使用或用「鉴物卷轴」后鉴定同类**。装备带有 +N/−N 附魔与祝福 / 诅咒；**被诅咒的装备无法普通卸下，需「解缚卷轴」**。
- **门、宝箱、陷阱（0.2）**：门分敞开 / 关闭 / 上锁，关闭的门阻挡移动与视线（可推开、踹开、长按关门）；宝箱可能上锁或带陷阱；陷阱默认隐藏（尖刺 / 毒气 / 传送 / 索套），可「搜索」发现、走向其拆除，铜灯旅人照明可大范围照见。
- **怪物特性（0.2）**：低血逃跑、保持距离、毒袭、开门、穿墙、守宝、偷金、死亡分裂 / 爆裂、迟缓重击等；Boss 半血进入第二阶段。
- **成长**：击败怪物获得经验，升级提升最大生命 / 攻击 / 防御并回复生命。
- **Boss 与结局**：第 5 层有 Boss「零环守卫」，击败后进入**胜利结算**；生命归零进入**死亡结算**。两者都会清除当前存档，但保留历史统计。
- **存档**：进度自动保存，主菜单「继续游戏」可读取未竟的旅程（旧存档自动迁移）。

## 操作说明

- **移动**：**点按地图上的任意位置，角色自动寻路前往**（途中遇到敌人会自动停下）；点按相邻怪物即近战，点按视线内远处怪物（持远程武器时）即远程攻击。桌面端也支持方向键 / WASD。
- **门与陷阱**：走向关闭的门即推开，走向上锁的门即踹门；走向**已显露的陷阱**即尝试拆除；**长按**相邻的敞开门可将其关闭。
- **查看格子**：**长按**地图某格，查看该格的地形、怪物或物品信息。
- **底部按钮**：技能、搜索、等待、背包、角色、日志、下楼。
  - 技能：释放本职业的主动技能（被动技能会提示自动生效）。
  - 搜索：消耗一回合搜寻四周隐藏的陷阱。
  - 背包：使用 / 装备 / 卸下物品（成功的物品动作消耗一回合）。装备为 **11 槽人偶**——主手 / 副手 / 头部 / 肩甲 / 身体 / 腰带 / 手套 / 足部 / 护符 / 戒指 ×2。
  - 角色 / 日志：查看属性、法力、技能、状态、装备与战斗记录。
  - 下楼：站在阶梯「>」上深入下一层。
- **设置**（主菜单右上「设置」）：音效开关、动画速度（慢 / 正常 / 快）、自动拾取金币。
- **安装为应用**：在支持的浏览器中可「添加到主屏幕」，以全屏 PWA 形式竖屏游玩。

## 项目结构

```
scripts/generate-assets.ts   # 原创像素素材 + 图标生成器（自带 PNG 编码器，零依赖）
public/
  manifest.json  sw.js       # PWA 清单与 Service Worker
  icons/                     # 生成的应用图标
  assets/generated/          # 生成的 spritesheet + atlas.json
src/
  main.ts  style.css         # 启动、缩放、黑底/安全区域/禁滚动
  game/
    config.ts                # 设计常量（尺寸、调色板、字体、场景键）
    scenes/                  # Boot / 主菜单 / 选职业 / 游戏 / 死亡 / 胜利 / 素材图鉴
    core/                    # RNG、FOV、回合系统、存档（含旧档迁移）、设置、类型
    systems/                 # 战斗、AI、背包、掉落、状态效果、物品实例与鉴定
    world/                   # 40×40 房间+走廊地牢生成、门/陷阱/宝箱、视线
    entities/                # Entity / Player / Monster
    data/                    # 职业、怪物、物品（原创设定）
    ui/                      # Button、Modal、MobileControls、背包、设置、特效
    assets/                  # atlas.ts（精灵加载/动画）；无版权素材
```
